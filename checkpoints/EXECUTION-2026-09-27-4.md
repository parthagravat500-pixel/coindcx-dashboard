# Executable evidence coverage — 2026.09.27.4

There are 50 implemented evidence adapters, up from 35. This release does not
implement all 10,000 catalog entries. Of the 50, 21 are source-pattern reviews,
13 are response observations, four use saved policy metadata, and 12 map to
bounded runtime comparisons. Runtime comparisons still require the appropriate
authorized runner, successful controls, current configuration and evidence.

The fixed owned-app sequence has 16 requests plus at most two existing exposure
repeats. All are loopback requests. Read-only API queries are paginated. Negative
write checks retain the existing empty body. Receipts keep hashes, statuses and
generated labels, never passwords, tokens or response bodies. Their step cap is
24 so successful controls cannot be silently dropped. Missing route controls
make a result inconclusive, not passed.

The new source rules run automatically over the existing fixed owned-source
inventory. They are never attributed to an external program. Incomplete parsing
cannot produce a clean-source status. No source is imported or executed.

## What still prevents universal execution

9,950 entries have no executable adapter. The 9,000 scenario variants are
combinations of core prompts and conditions, not ready-made test definitions.
Each needs an applicable feature, a concrete test procedure and expected result,
authorized resource bindings, and independent evidence. Examples include two
owned tenant identities, a payment sandbox, an approved mobile build, a revoked
session fixture, or controlled failure injection. Program-specific scope and
method permission are also required. Documentation and reporting judgments are
not universally decidable by a generic scanner.

These missing inputs and implementations are material blockers. Catalog
assignment, parent evidence, synthetic laboratory success and owned-app results
must never be presented as completed external-program tests. No expired batch is
restarted and no new external target or account is activated by this release.
